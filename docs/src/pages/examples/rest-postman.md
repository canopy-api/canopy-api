---
title: Postman
description: Try the Canopy REST API using the public Postman collection.
---

A public [Postman REST collection](https://www.postman.com/rhin-0-s-team/canopy-api-amazon-product-data-api-rest-graphql-mcp/collection/n2edm6b/rest) is available for sending requests without writing code.

---

1. Open the [REST collection](https://www.postman.com/rhin-0-s-team/canopy-api-amazon-product-data-api-rest-graphql-mcp/collection/n2edm6b/rest) in Postman.
1. Add your API key as an `API-KEY` header, or as `Authorization: Bearer YOUR_API_KEY`.
1. Send a request.

The same [Postman workspace](https://www.postman.com/rhin-0-s-team/canopy-api-amazon-product-data-api-rest-graphql-mcp/overview) also includes GraphQL and MCP collections.
