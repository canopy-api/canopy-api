---
title: Postman
description: Try the Canopy GraphQL API using the public Postman collection.
---

A public [Postman GraphQL collection](https://www.postman.com/rhin-0-s-team/canopy-api-amazon-product-data-api-rest-graphql-mcp/collection/6ubxfrt/graphql) is available for sending queries without writing code.

---

1. Open the [GraphQL collection](https://www.postman.com/rhin-0-s-team/canopy-api-amazon-product-data-api-rest-graphql-mcp/collection/6ubxfrt/graphql) in Postman.
1. Add your API key as an `API-KEY` header, or as `Authorization: Bearer YOUR_API_KEY`.
1. Send a query.

The same [Postman workspace](https://www.postman.com/rhin-0-s-team/canopy-api-amazon-product-data-api-rest-graphql-mcp/overview) also includes REST and MCP collections.
